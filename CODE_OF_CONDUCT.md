# Code of Conduct

## Our pledge

We want Nautilus to be a project people are glad they contributed to. Everyone
is welcome regardless of experience level, background, identity or which side of
the tabs-versus-spaces argument they're on.

## Expected behaviour

- Be direct and be kind. Both are possible at once.
- Critique code, not people. "This will break on cyclic graphs" beats "this is
  wrong".
- Assume good faith. Most disagreements are missing context, not malice.
- Respect maintainers' time: search before filing, and include enough detail to
  reproduce.
- Respect contributors' time: review promptly or say when you can't.

## Unacceptable behaviour

Harassment, discriminatory language, personal attacks, sustained disruption,
publishing others' private information, or any conduct that would make a
reasonable person feel unwelcome.

## Enforcement

Report problems to the maintainer via GitHub (open an issue if it can be public,
or contact the maintainer directly if it can't). Maintainers may edit, remove or
reject contributions and comments that violate this document, and may block
repeat offenders.

This code applies in issues, pull requests, discussions and any other project
space.

Adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/).
